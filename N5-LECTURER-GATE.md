# N5 lecturer guide for the first evidence gate

Use Week 1, Class 1 in the N5 mastery pathway. The outcome is that the learner can read an instruction, plan an action, produce its output and verify the file independently. Use an empty practice folder and synthetic names.

## Demonstrate

Say: “Make a copy of a blank document and save the copy as Campus-Plan. Before touching the keyboard, tell me the action, the output and how you will prove you finished.”

Explain that a command verb tells us what to do. A filename identifies the expected output. Verification means reopening the saved copy and checking its contents and location. Model all three steps aloud. Open the original again so students see how to distinguish the original from the copy.

## Guided correction

Say: “You edited the original. Which word in the instruction tells us to preserve it? Show me where the copy should be.” If a student feels stuck, offer the optional reframe “I can check one step at a time.” Give time to retry. Ask the learner to predict whether the copy will open from the practice folder, then test that prediction.

## Independent reassessment

Give a fresh instruction: “Copy a timetable into a different folder, rename it Week-Two, and show that the original timetable still opens.” Ask the learner to state the action and expected evidence, perform it, and independently verify both files.

## Lecturer decision

Record observed, needs practice or unobserved separately for command interpretation, producing the requested file and verifying the original and copy. Record the observed action beside each decision. If evidence is missing, ask for a fresh demonstration. Use an ambiguous response for moderation. A second lecturer should independently deliver the lesson and compare decisions using synthetic evidence before the gate is approved.
